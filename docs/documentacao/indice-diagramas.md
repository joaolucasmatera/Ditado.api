## Regras

- Toda fonte deve ser editável e versionada.
- PNG ou SVG são complementos; não substituem `.mmd`, `.puml`, `.drawio` ou Markdown Mermaid.
- Cada diagrama deve registrar finalidade, fontes, premissas, status e seção do relatório.
- Propostas devem ser visualmente identificadas como propostas e não podem ser usadas como prova do schema ou comportamento implementado.
